# me-qfactor-budget

Per-channel energy-loss budget predicting the quality factor of
magnetoelectric (ME) laminate composites without structural fitting.

Companion code for the manuscript:

> H. Talleb, *A per-channel energy-loss budget predicts the quality factor
> of magnetoelectric laminate composites without structural fitting*,
> submitted to Smart Materials and Structures (2026).

Every number, table and figure of the paper is generated by the scripts in
this repository.

## What it does

The mechanical quality factor Q of a resonant ME laminate is usually a
number fitted a posteriori on the fabricated sample (directly, or through
Rayleigh damping coefficients). This code predicts it from material data
alone, through the budget 1/Q = sum_i 1/Q_i over five channels:

1. PZT mechanical loss (Q_m x energy fraction);
2. PZT dielectric loss;
3. eddy currents in the conductive magnetostrictive layer, driven by the
   motional flux b* = lambda d33m T, with the demagnetizing flux factor
   lambda = (1-N)/(1+chi N) computed exactly (`demag_lambda.py`);
4. stress-driven Rayleigh hysteresis (`qfactor_hysteresis.py`), amplitude
   dependent, solved self-consistently (nonlinear Q(h_ac));
5. epoxy-bond shear lag.

Validation: one frozen material table against the four PZT-5H/Terfenol-D/
Metglas laminates measured in K. Malleron's thesis (Sorbonne Universite,
2018) and Malleron et al., Microelectronics Journal 88, 184-189 (2019).

## Run

```bash
python3 run_budget.py        # full report + 3-panel figure
python3 verify_qfactor.py    # verification suite (17 self-contained tests)
python3 make_figures_en.py   # the 6 figures of the manuscript
```

Requires Python 3 with numpy and matplotlib only.

`run_fem2d_crosscheck.py` (test 18, figure 6) additionally requires an
internal 2-D coupled FEM solver that is not distributed here; the
verification suite skips it cleanly when absent. All budget results are
produced by the self-contained scripts above.

`make_refs.py` rebuilds `refs_verified.json`, the Crossref-canonical
metadata of the 35 references: the manuscript bibliography is generated
from this file, so no reference metadata is ever typed from memory.

## Files

| file | role |
|---|---|
| `qfactor_model.py` | structural model (two-segment bar FEM, open-circuit rank-one stiffening), the five channels, interval corners, inverse bounds, self-consistent Q(h_ac) |
| `demag_lambda.py` | exact magnetometric demagnetizing factor N of a rectangular prism (self-tests: cube = 1/3, sum rule = 1) and lambda = (1-N)/(1+chi N) |
| `qfactor_hysteresis.py` | generalized Rayleigh minor-loop loss, stress-equivalent field swing |
| `run_budget.py` | report: reference budget, 4-sample validation, Q(h_ac), inverse bounds |
| `verify_qfactor.py` | 18 automated tests (analytic limits, sum rules, bandwidth-budget identity, mesh convergence, sample brackets) |
| `make_figures_en.py` | manuscript figures |
| `fig_en_*.png` | pre-built figures |
